Task 8: Simple Sales Dashboard Design

Objective :-
To design a basic interactive Power BI dashboard that visualizes sales performance across products, regions, and months, helping business users quickly identify trends and high-performing areas.

Tools Used :-
Power BI Desktop (for dashboard design)

Dataset: Superstore_Sales.csv

Columns used: Order Date, Region, Category, Sales, Profit

 Files Included :-
 Data visualization 8.pbix – Power BI file with completed dashboard

 Task 8 visualization.pdf – Exported view of dashboard

 README.md – This file

 Steps Followed
Data Import :-
Loaded Superstores.csv into Power BI.

Data Transformation :-

Converted Order Date to a "Month-Year" format using:
MonthYear = FORMAT([Order Date], "MMM-YYYY")

Dashboard Visuals

 Line Chart: Sales trends over months

 Bar Chart: Total Sales by Region

 Donut Chart: Sales by Category

Interactivity :-

Added Slicer for Region selection

 Key Insights (from Insights.txt) :-

Count of MonthYear and Sum of Sales by Region

 Outcome
This project demonstrates the creation of a clean, insightful dashboard that helps stakeholders quickly interpret sales data, monitor performance by segment, and make informed business decisions.
